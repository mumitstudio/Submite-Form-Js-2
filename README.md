# Contact Form

A clean and responsive **Contact Form UI** built with **HTML, CSS, Bootstrap, and JavaScript**.  
The form includes fields for Email, Phone, Subject, and Message, along with a modern Submit button.

## 📸 Preview

![Contact Form Preview](image.png)

## ✨ Features

- Clean and modern user interface
- Fully responsive layout
- Bootstrap-based styling
- Email input field
- Phone input field
- Subject input field
- Message field
- Submit button
- Easy to customize and extend
- Suitable for websites, portfolios, business websites, and contact pages

## 🛠️ Technologies Used

- **HTML5** – Structure of the form
- **CSS3** – Custom styling and layout
- **Bootstrap 5** – Responsive design and UI components
- **JavaScript** – Form validation and interaction

## 🚀 How to Use

1. Clone or download this repository.
2. Open the project folder.
3. Make sure `index.html`, `style.css`, and `script.js` are connected correctly.
4. Open `index.html` in your web browser.

## 📝 Form Fields

| Field | Description |
|---|---|
| Email | User's email address |
| Phone | User's phone number |
| Subject | Message subject |
| Message | User's message |
| Submit | Sends/submits the form |

## 🔧 Customization

You can easily customize:

- Form width and spacing
- Border radius
- Button colors
- Typography
- Input styles
- Bootstrap classes
- Validation rules
- Form submission behavior

## 📱 Responsive Design

The form is designed to work smoothly across:

- 💻 Desktop
- 💻 Laptop
- 📱 Tablet
- 📱 Mobile

## 📌 Note

This project focuses on the **front-end form interface and validation**.  
To actually send submitted messages to an email address or database, a backend or form-processing service needs to be connected.
